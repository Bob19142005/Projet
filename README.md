Networking Project /Lab 

The network diagram represents the infrastructure of SKYNET CORP, which is organized using Virtual Local Area Networks (VLANs) to separate employees by department. The network includes four main VLANs: VLAN 20 (Marketing), VLAN 30 (Operations), VLAN 50 (Human Resources), and VLAN 80 (IT). Each department has its own computers and printers connected to network switches. By separating departments into different VLANs, the company improves network security, reduces unnecessary traffic, and makes the network easier to manage.

The topology also includes multiple switches connected by trunk links, allowing all VLANs to communicate between the main office and the new office while remaining logically separated. An ISR4331 router is connected to the network to provide inter-VLAN routing, which enables devices in different VLANs to communicate when necessary. This design ensures efficient communication across the company while maintaining security and organization by keeping each department's network traffic isolated.
